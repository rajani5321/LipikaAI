🤖 6-Pillar System Architecture

MCA Real-World Implementation

🌐 1. Web Development

HTML5, Responsive Glassmorphic CSS3, Vanilla JS. Real-time updates, client-side filtering, interactive modals.

⚙️ 2. Backend

FastAPI async REST architecture. Modular routers, Pydantic type safety, automated Swagger & ReDoc documentation.

📄 3. Document Processing

pypdf & python-docx text extraction. Multi-format sanitation, paragraph & table extraction, character normalizer.

🧠 4. Natural Language Processing

400+ tech skills ontology, regex entity extraction for email/phone/tenure, degree hierarchical classification.

🤖 5. Machine Learning

TF-IDF vectorizer + Cosine Similarity semantic matching. Multi-factor weighted composite scoring with explainable verdicts.

🗄️ 6. Database (MongoDB)

PyMongo driver with dual-mode architecture: connects to live MongoDB Atlas/local, with automatic fallback to embedded document engine.
